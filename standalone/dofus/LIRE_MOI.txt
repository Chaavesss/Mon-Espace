COMPAGNON DOFUS INDÉPENDANT 1.7.1 — WINDOWS 10/11 x64

INSTALLATION
Fermer l’ancienne version. Extraire tout le ZIP puis lancer Installer_Compagnon_Dofus.cmd.
L’exécutable, les DLL et THIRD_PARTY_NOTICES.txt doivent rester ensemble.
L’installation est propre à votre session Windows, sans droit administrateur.
Version portable : lancer CompagnonDofus.exe dans le dossier complet extrait.

DÉMARRAGE
L’application s’ouvre sur la grande bibliothèque.
La préparation initiale télécharge automatiquement tous les guides publics Tougli / Ganymède des catalogues inclus : garder Internet pendant cette étape.
Une barre indique les guides prêts ; interrompre conserve ce qui est déjà téléchargé. La prochaine ouverture reprend les guides manquants.
Une source indisponible est annoncée : la préparation n’est pas déclarée complète s’il manque des guides.
Configurer le personnage puis choisir son parcours. Charger le guide et ouvrir l’overlay démarre la vue compacte.
Personnage · Guides revient à la bibliothèque. La recherche et les filtres servent à trouver les autres parcours.
Les guides et instructions chargés sont conservés localement. Images et contenus interactifs restent consultables dans le guide source.
Le bouton Actualiser le guide sélectionné récupère une nouvelle version sans supprimer vos validations.

PORTRAIT
Choisir une image accepte PNG, JPG ou WebP jusqu’à 10 Mo / 40 millions de pixels.
L’aperçu est conservé seulement après Enregistrer et choisir un parcours.
L’overlay affiche le personnage entier sans recadrage, à côté du Dofus associé au parcours. Ce bandeau reste visible pendant le défilement.
Le portrait est converti localement en PNG de 384 × 384. Votre original n’est ni modifié ni envoyé.
Retirer puis enregistrer supprime son association au personnage. Chaque personnage garde son propre portrait.

PROGRESSION
Terminé valide une étape ; les flèches changent d’étape sans valider.
Les coordonnées entre crochets copient /travel x,y ; aucun déplacement automatique.
La barre affiche la proportion des étapes validées pour le personnage et le parcours actifs.
Les quêtes Tougli reconnues sont partagées entre parcours par identifiant de jeu. Les quêtes Ganymède associées peuvent être validées explicitement dans le panneau Quêtes associées.
Un nom exact normalisé sert uniquement lorsque l’identifiant du jeu n’est pas disponible. Aucune correspondance approximative.
Une instruction ou un trajet ne vaut pas validation d’une quête entière.
Les personnages ont des validations séparées. Les anciennes quêtes Tougli validées sont reprises lorsque leurs guides locaux sont lisibles.
Les cas ambigus ou choix de classe / alignement non renseignés ne sont pas devinés.

STYLE DES INSTRUCTIONS GANYMÈDE
Style compagnon présente des consignes au tutoiement, des actions directes et des repères de préparation / conditions. Le profil du personnage actif est rappelé.
Texte source revient au texte du guide ; Lire le texte source complet reste disponible dans la vue compagnon. Le choix est conservé.
La reformulation fonctionne localement par règles prudentes, sans clé API et sans service IA payant. Les formulations non reconnues restent conservées ; il ne s’agit pas d’une réécriture libre de tous les paragraphes.
Dialogues entre guillemets, conditions et informations du jeu sont conservés. Le logiciel ne devine pas la branche à suivre selon la classe ou l’alignement : les conditions du guide restent à vérifier.
Les versions affichées sont mises en cache localement dans Data/InstructionViews, séparément des guides sources et de votre progression. Une source actualisée génère une nouvelle vue.
Les coordonnées restent cliquables et les crédits des auteurs restent affichés. Ce mode s’applique aussi aux extraits Ganymède des parcours Tougli.

SONGES
Le bouton Songes ouvre le chrono dédié. Sélectionner la fenêtre DOFUS, activer la détection puis revenir dans le jeu au premier plan.
FIN DE TOUR démarre le combat ; le résultat VICTOIRE / DÉFAITE l’arrête. La profondeur indique la salle, pas le nombre de combats.
Temps total, temps par salle et temps de combat sont distincts. Marchés et bonus ne sont pas comptés comme combats.
Le marché final est en 25, le combat à vagues en 26 ; le chrono continue entre les vagues.
Le bilan Songe terminé fournit le temps officiel ; une saisie manuelle permet de corriger une lecture manquée.
Les images sont analysées localement en mémoire, sans enregistrement ni envoi. Pas de lecture mémoire, d’injection ou d’action dans le jeu.
Reconnaissance expérimentale : vos repères doivent être visibles. OCR Windows français requis ; commandes manuelles disponibles.

MISES À JOUR
Vérification au lancement et à la demande. Une nouvelle version affiche un indicateur dans la bibliothèque et sur le compagnon.
Le bouton ouvre le téléchargement ; l’installation reste manuelle, sans mise à jour silencieuse.
Cette version doit être installée une première fois pour bénéficier de ce contrôle.

DONNÉES
Application : %LOCALAPPDATA%\CompagnonDofus\App
Données : %LOCALAPPDATA%\CompagnonDofus\Data
Sauvegarder tout le dossier Data après fermeture conserve personnages, portraits, guides et progression.
Aucun accès aux données de Mon espace et aucune synchronisation avec les comptes Tougli / Ganymède.
Chaque session Windows possède ses propres données.
La préparation des guides se fait sur votre PC ; les textes des guides ne sont pas redistribués dans ce ZIP.

SESSION, NOTES ET PRÉPARATION
Reprendre ma dernière session Dofus dans la bibliothèque retrouve personnage, parcours et étape. Notes · Préparer dans Actions de l’étape ouvre les notes et la liste de préparatifs. Les coches sont personnelles, sans lecture de l’inventaire. Ajouter un préparatif par ligne, actualiser la liste puis enregistrer.

RÉGLAGES OVERLAY
Actions de l’étape > Réglages overlay : tailles des images, opacité et éléments visibles. Enregistrer applique les changements ; annuler conserve les réglages précédents.

RECORDS SONGES
Records et comparaison des salles sépare temps officiels et mesurés. Les salles enregistrées sont comparées à la meilleure run victorieuse mesurée. Les archives restent locales ; Nouvelle run archive le bilan précédent. Les salles absentes ne sont pas inventées et les défaites ne deviennent pas des records.
