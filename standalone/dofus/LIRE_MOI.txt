COMPAGNON DOFUS INDEPENDANT 1.0 — Windows 10/11 x64

1. Extraire tout le ZIP.
2. Double-cliquer sur Installer_Compagnon_Dofus.cmd pour installer et créer les raccourcis.
   Ou ouvrir CompagnonDofus.exe directement pour l'utiliser sans installation.
3. Dans Personnage · Guides : renseigner le personnage, puis Enregistrer.
4. Choisir Rush Sylvestre Accéléré ou Dofus Sylvestre et Charger / actualiser.
   Tous les guides permet de rechercher les autres parcours publics Tougli.
5. Fermer les réglages : l'overlay reste ouvert, redimensionnable et épinglable.

Terminé valide l'étape et avance. Suivant avance sans valider. Annuler retire la validation.
Reprendre à cette étape permet de rejoindre une progression existante manuellement.
X ferme complètement le compagnon. Alt + Tab permet de le retrouver.
Les guides chargés fonctionnent hors ligne ; le chargement et les liens nécessitent Internet.

Installation par utilisateur, aucun droit administrateur demandé.
Application : %LOCALAPPDATA%\CompagnonDofus\App
Personnages, progression et cache : %LOCALAPPDATA%\CompagnonDofus\Data
Pour sauvegarder, fermer l'application puis copier ce dossier Data.
Pour désinstaller, fermer l'application puis supprimer le dossier App et ses raccourcis.
Conserver Data pour retrouver sa progression après réinstallation.

Cette application n'installe pas Mon espace et n'accède pas à ses données.
Pas de synchronisation automatique entre les deux applications ni avec un compte Tougli.
Chaque utilisateur Windows possède ses propres données.
Pas de lecture du jeu, d'automatisation de combat ou d'injection dans DOFUS.
L'overlay fonctionne comme une fenêtre Windows ; le mode fenêtré sans bordure du jeu est conseillé.
Les instructions détaillées s'ouvrent dans le navigateur habituel.
Les choix inconnus ne sont pas devinés : renseigner classe, alignement et ordre.
Le compteur de ressources ne connaît pas l'inventaire.

Source : Tougli — Toufloux et Gligo, https://tougli.barbofus.com/guides
Outil indépendant, non affilié à Ankama, Tougli ou Ganymède.
Aucun guide Tougli n'est distribué dans le ZIP : chargement public à la demande.
Windows peut afficher un avertissement pour cet exécutable non signé.
