# Ma journée — version 1.4

## Trois priorités

Sur l’accueil, cliquer sur **Choisir mes 3 priorités** ou **Choisir** dans le bloc Mes priorités. Rechercher une tâche ou un projet, puis sélectionner jusqu’à trois tâches. Les tâches terminées restent cochées dans la sélection du jour ; le lendemain, l’application repart sur des suggestions. Les suggestions proposent le retard, puis les échéances d’aujourd’hui, avant les autres tâches. Le choix **Suggestions automatiques** rend la sélection à l’application.

## Reprendre le travail

Le bouton **Reprendre le dernier** et le bloc **Reprendre où j’en étais** retrouvent les projets, notes et documents récemment ouverts. L’historique est conservé sur ce PC après fermeture. Aucun contenu n’est ouvert automatiquement au démarrage. Les éléments supprimés ou les fichiers absents sont ignorés. Effacer l’historique ne supprime aucun contenu. Le mode discret n’enregistre pas de nouvelles entrées.

## Captures et boîte de réception

Le bouton **+ Capturer** conserve le raccourci et les choix existants : **À trier**, **Tâche** ou **Note**. Les captures À trier se retrouvent dans **Réception** dans la navigation et via le compteur sur l’accueil. Cliquer sur **Classer cette idée** pour créer une tâche, une note ou un projet en gardant les détails. Une capture déjà classée conserve un lien vers le contenu créé. Les créations directement classées en tâche ou note ne sont pas dupliquées dans la réception.

## Déplacer et redimensionner les blocs

1. Sur l’accueil, cliquer sur **Déplacer les blocs**.
2. Glisser la poignée à gauche du titre d’un bloc vers un autre bloc pour le placer avant celui-ci.
3. Déposer à gauche ou à droite pour choisir la colonne ; maintenir **Ctrl** pendant le dépôt pour utiliser toute la largeur.
4. Tirer le coin inférieur droit pour régler la hauteur. Un déplacement horizontal marqué vers la droite passe en pleine largeur ; vers la gauche, il réduit un bloc large à la colonne gauche.
5. Le menu **···** propose aussi la colonne, la pleine largeur, la hauteur automatique, les tailles Compact/Normal/Grand et le masquage.
6. Cliquer sur **Terminer l’organisation**.

Les blocs à hauteur fixe défilent à l’intérieur si leur contenu dépasse. Les contenus ne sont pas coupés ni supprimés. Les choix restent enregistrés après redémarrage. Le réglage **Organiser mon accueil** permet toujours de réafficher un bloc masqué.

## Un accueil par mode

Ouvrir **Mes modes**, puis créer ou modifier un mode. Les boutons **+ Travail**, **+ Dofus** et **+ Perso** fournissent des exemples que vous pouvez adapter avant de les enregistrer.

- **Accueil à afficher avec ce mode** : aucun changement, Travail, Dofus, Perso ou une copie de votre accueil actuel.
- **Priorités et tâches de cet accueil** : tous les projets ou un seul projet.
- Les applications, dossiers et sites à lancer se configurent comme auparavant. Un mode peut aussi ne changer que l’accueil.
- Les ouvertures commencent seulement en cliquant sur **Lancer**. Le modèle Dofus propose Spotify ; choisir soi-même Ankama Launcher et ajouter la bonne adresse Tougli dans les actions.
- Déplacer ou redimensionner des blocs dans un mode conserve cette disposition pour ce mode.
- **Revenir à mon accueil** restaure la disposition habituelle. Cela ne ferme aucune application.

Les trois priorités sont une sélection quotidienne commune à cet espace ; le filtre de projet d’un mode affiche la partie correspondante de cette sélection. Chaque PC et chaque utilisateur possèdent leurs réglages indépendants.

## Agenda Google

La synthèse affiche les rendez-vous locaux et ceux du calendrier Google chargé. Le bouton Actualiser Google et l’indication d’actualisation permettent de savoir si les données Google sont disponibles. La connexion Google doit avoir été configurée séparément ; aucun accès à un compte n’est fourni avec l’application.

## Vérifications

Les suites couvrent la migration des anciennes données, la sélection et la conservation des priorités terminées, le changement de jour, les éléments récents supprimés ou renommés, la confidentialité, les dispositions indépendantes par mode, leur restauration, les vrais boutons WPF de sélection et de tri, et les événements du contrôle de redimensionnement. Le glisser-déposer physique, les raccourcis globaux et les connexions réelles restent à confirmer sur le PC d’utilisation.


## Version 1.10 : dispositions, session et bilan

Sur l’accueil, Dispositions permet de nommer jusqu’à douze configurations des blocs. Le déplacement par poignée et le redimensionnement par le coin des cartes restent disponibles dans Déplacer les blocs. Appliquer une disposition ne change pas les tâches ou notes.

Reprendre ma session retrouve les onglets, documents locaux disponibles et panneau latéral. La restauration au démarrage est facultative dans Dispositions. Les documents réseau ou absents ne sont pas ouverts automatiquement. Les textes sont simplement rouverts, sans écrasement des fichiers. Les brouillons non enregistrés suivent toujours la confirmation à la fermeture.

Bilan de la journée montre les tâches terminées et permet de choisir explicitement celles à reporter à demain. Une note prépare le lendemain. Les bilans sont conservés localement avec un historique borné ; les tâches non cochées restent inchangées.

Connexions distingue une session enregistrée d’un accès testé. Le bouton Tester effectue des lectures sur Google Drive, Agenda et Spotify, ainsi que la détection du lecteur local. Le bot est affiché uniquement si son module est activé. Son point de santé HTTPS public ne doit contenir aucun identifiant ni jeton ; le logiciel distingue la réponse HTTP de l’état Discord lorsque le serveur le fournit. La configuration du bot côté serveur n’est pas modifiée par Mon espace.
